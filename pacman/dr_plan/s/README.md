# Pac-Man Game

A Python implementation of the classic Pac-Man arcade game using Pygame.

## Setup

1. Install the required dependencies:

```bash
pip install -r requirements.txt
```

2. Run the game:

```bash
python main.py
```

## Controls

- Use arrow keys to control Pac-Man
- Press ESC to pause/unpause
- Press Q to quit

## Features

- Classic Pac-Man gameplay
- Ghost AI with different behaviors
- Power pellets and ghost vulnerability
- Score tracking and lives system

## Project Structure

```
.
├── assets/
│   ├── images/      # Game sprites and images
│   └── sounds/      # Sound effects
├── entities/        # Game entity classes
├── systems/         # Game systems (collision, rendering, etc.)
├── main.py         # Game entry point
└── requirements.txt # Project dependencies
```
