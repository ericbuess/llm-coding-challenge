# Pacman Game in Python

A simple implementation of the classic Pacman game using Pygame.

## Requirements
- Python 3.x
- Pygame

## Installation
```
pip install pygame
```

## How to Play
- Run `python pacman.py` to start the game
- Use arrow keys to control Pacman
- Eat all pellets to win
- Avoid ghosts unless you've eaten a power pellet
- Press 'R' to restart after game over or winning

## Features
- Classic Pacman gameplay
- Four ghosts with basic AI
- Power pellets that let you eat ghosts
- Score tracking
- Multiple lives
